- Developed a real-time ASL fingerspelling translator using a confidence hybrid classifier, routing 30fps webcam frames through a fast landmark MLP (97.5% accuracy) with CNN fallback, achieving ~99.9% accuracy.
- Trained both models on 87,000 Kaggle ASL images across 29 classes, implementing scale-invariant landmark normalization (wrist-centered, bounding-box-scaled) that boosted MLP accuracy 15% above projected baseline.
